## Что строим

При подаче заявки на гида для каждого выбранного языка (кроме родного) добавляем короткий голосовой тест: AI задаёт 2–3 вопроса на этом языке, гид отвечает голосом, мы расшифровываем речь (ElevenLabs Scribe) и AI (Gemini) оценивает уровень CEFR (A1–C2) + ставит балл. Результат сохраняется к заявке, виден админу и отображается значком уровня в профиле гида.

## Пользовательский поток

1. В форме `become-a-guide` после выбора языков появляется секция "Проверка языка".
2. Для каждого языка — карточка со статусом: «Не пройдено» / «Пройдено: B2».
3. Кнопка «Пройти тест» открывает модалку:
   - Шаг 1: проверка микрофона + кнопка «Начать».
   - Шаг 2–4: AI озвучивает вопрос (TTS) → гид отвечает (запись ≤ 30 сек) → автостоп по тишине → перейти к следующему.
   - Шаг 5: «Анализируем…» → показываем оценку (уровень + краткий фидбек).
4. Без прохождения теста хотя бы одного языка кнопка «Отправить заявку» неактивна (опционально: разрешить отправить, но язык будет «не верифицирован»).

## Технические детали

**База данных** (новая миграция):
- `guide_language_tests` — `id`, `application_id`, `language` (ru/en/uz/…), `level` (A1–C2), `score` (0–100), `transcript` (jsonb: массив Q&A), `feedback` (text), `created_at`. RLS: insert/select для владельца заявки и админов.
- Добавляем `language_levels jsonb` в таблицу заявок (`{ "en": "B2", "ru": "C1" }`) для быстрого чтения в профиле.

**Сервер** (`createServerFn` в `src/lib/language-test.functions.ts`):
- `getLanguageTestQuestions({ language })` — Gemini генерирует 3 вопроса на выбранном языке (нарастающей сложности).
- `submitLanguageTestAnswer({ audioBase64, language, question })` — расшифровка через ElevenLabs Scribe (batch).
- `gradeLanguageTest({ applicationId, language, qa })` — Gemini оценивает по CEFR, сохраняет в `guide_language_tests`, обновляет `language_levels`.

**TTS вопросов**: ElevenLabs `eleven_multilingual_v2` через серверную функцию `synthesizeQuestion`, возвращает mp3 (base64 или blob).

**Клиент**:
- Новый компонент `LanguageTestDialog` (MediaRecorder API).
- Интеграция в `become-a-guide.tsx` рядом со списком языков.
- Бейдж уровня (`B2`, `C1`) в `GuideCard` и на странице гида.

**Зависимости**:
- ElevenLabs подключается как standard connector (`ELEVENLABS_API_KEY`).
- Lovable AI Gateway для Gemini уже есть в проекте.

**i18n**: ключи для UI теста (RU/EN/UZ) — заголовки модалки, инструкции, статусы.

## Что НЕ входит

- Live-стриминг расшифровки (используем batch для простоты и точности).
- Перезапись отдельных вопросов (только пересдача всего теста).
- Антифрод/защита от подмены голоса.
